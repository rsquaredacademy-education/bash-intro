# Solutions — Introduction

1. `whoami` prints your username; `date` prints the current date, time, and timezone; `cal` prints this month's calendar. After `clear` (or `Ctrl + L`) you should see a blank prompt with no scrollback visible.
2. The first 12 lines of `ls --help` document common flags such as `-a` (do not ignore hidden entries), `-l` (long listing format), and `-h` (human-readable sizes). On Git Bash, `man ls` reports "No manual entry" — use `<command> --help` instead.
3. Answers vary. A useful `tldr ls` example not in the chapter: `ls -ltr` (long listing, oldest first — newest file at the bottom).
